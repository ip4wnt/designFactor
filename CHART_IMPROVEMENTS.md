# Улучшения визуализации графиков

## Что изменено
- Импорт Excel выбирает график по данным, имя листа больше не влияет.
- Даты Excel и строки YYYY-MM-DD, YYYY-MM, DD.MM.YYYY, YYYY/MM/DD определяют временной ряд; даты сортируются перед построением линии.
- Текст цели «сравнить» выбирает столбцы; «доли»/«структура» выбирает круговую для 2–6 категорий, одной серии, без пропусков и отрицательных значений.
- API import-excel принимает необязательное поле формы goal; если его нет, используется purpose слайда.
- Числа с пробелами и десятичной запятой распознаются. Пустые значения сохраняются как null и отображаются разрывом линии. Текст и NaN не превращаются в нули.
- Круговая диаграмма: разные фирменные цвета секторов, легенда категорий, проценты.
- Линии: явный цвет и толщина из палитры шаблона.
- На графиках с более чем 12 категориями отключены подписи каждого значения, чтобы уменьшить наложения.
- У столбцов с неотрицательными значениями шкала начинается с нуля.
- Целые числа в подписях не получают лишний десятичный разделитель.
- Сохраняются существующие пределы чтения Excel: 500 строк вместе с заголовком и 50 столбцов.
- Автоматический импорт оставляет большие наборы (более 60 строк данных или 6 серий) таблицами. Справочник из 200 строк не превращается в 200 столбиков. Разбиение больших таблиц на слайды этим изменением не добавлено.
- Excel-файлы закрываются после чтения, в том числе при ошибке.

## Проверка
Из backend, в окружении с установленными requirements.txt:

```powershell
python -m unittest discover -s tests -v
```

Пять тестов проверяют выбор, цель, сортировку, пропуски, неверные значения, справочник из 200 строк и сохранение/повторное открытие настоящего PPTX с тремя типами диаграмм.
Проверка структуры PPTX автоматическая. Сравнение прежнего и нового оформления на одинаковых условных данных экспортировано в PNG через установленный PowerPoint и проверено визуально: круговая, линия, плотная столбчатая диаграмма. Проверка развёрнутого приложения не выполнялась.

## Что показать команде
1. Обычный Excel-лист (не chart): Date / Revenue; строки 2026-02 / 120 и 2026-01 / 100. Результат — линия в правильном порядке дат.
2. Region / Revenue: Москва / 120, Казань / 90, Самара / 65. Результат — столбцы.
3. Product / Revenue: A / 55, B / 30, C / 15; goal=показать доли. Результат — круговая с разными цветами, легендой и процентами.
4. Для временного ряда оставить одну числовую ячейку пустой: линия имеет разрыв, нуля на её месте нет.

Примеры готовых ContentBlock лежат в examples/chart-improvements/*.json. Их можно отправлять в существующий POST /jobs/{job_id}/slides/{slide_id}/content-block. После добавления блока или импорта Excel вызвать POST /jobs/{job_id}/fix для пересборки (существующий порядок API).
Примеры синтетические. API-ключ и SSH для этой доработки не нужны.

## Границы изменения
Это улучшение существующего импорта Excel и общего оформления диаграмм. Оно не добавляет поддержку новых форматов файлов, новых типов графиков, генерацию аналитических выводов или загрузку брендбука. Полное соответствие ТЗ второго этапа не заявляется.

## Подписи осей, единицы и длинные категории
ChartData дополнен необязательными полями category_axis_title, value_axis_title,
units, source и orientation (auto / vertical / horizontal). Старые JSON-планы
продолжают приниматься. Для одной серии название метрики берётся из её имени.
Единицы и источник не выдумываются, если их нет во входных данных.

Заголовки колонок Excel используются как подписи осей. import-excel дополнительно
принимает поля формы units и source. Без source используется имя загруженного файла.
Отдельные элементы управления этими полями в интерфейс не добавлены.

В режиме auto столбцы становятся горизонтальными, если хотя бы одно название
категории длиннее 18 символов. Состав категорий, порядок и значения сохраняются.
orientation=vertical позволяет оставить вертикальные столбцы, horizontal — явно
выбрать горизонтальные. Для линии и круговой orientation не меняет тип графика.
Источник размещается в выделенной области под графиком внутри исходной рамки.
Общий рендерер подключён к assembly, library, slide_clone и template_engine.

Проверки: 13 тестов, включая импорт Excel через HTTP API, старый формат JSON,
сохранение осей и источника в PPTX, единицы без повторов, горизонтальные столбцы,
замену объекта шаблона, подписи на тёмном фоне и сохранение пропусков.
Примеры с длинными категориями, временным рядом и тёмным фоном экспортированы
в PNG через PowerPoint и проверены визуально. Генерация через внешний LLM и
работающее развёрнутое приложение этой проверкой не покрываются.

Ошибка извлечения фона или применения стиля логируется и не мешает сохранить нативный график и подписи.
